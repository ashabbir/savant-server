## Policy interpretation

The transcribed requirements leave the per-domain setting unnamed. This change
uses `metadata.contemplate_similarity_threshold`: a finite number in `[0,1]`,
or `"default"` for `KG_CONTEMPLATE_SIMILARITY_THRESHOLD` (default `0.70`). All
root domains need an explicit policy and non-empty matching names. The strictest
applicable threshold wins. Unscoped workspace membership alone does not authorize
an automatic merge. Exact matching uses non-empty normalized title OR content;
semantic similarity is an alternative, not an additional exact-text requirement.
These choices replace the older workspace-only, 0.95, 20-node contract.

## TDD and final checks

Tests were first run against the previous implementation and failed for structural
artifact replacement, missing Markdown subprocess isolation, semantic threshold
matching, scheduler opt-out, generated-content pruning, invalid UTF-8 handling,
Markdown LST coverage, and missing domain-policy report data. Implementation then
made those regressions pass. A later regression caught model failure after an
exact merge; the refreshed-vector path now defers that review safely.

The final focused run passed **167 tests** against an isolated disposable
PostgreSQL 16 / pgvector container, with models forced offline. No production
database was used. `git diff --check`, Python parsing of changed files, and
`sh -n docker-entrypoint.sh` pass. Four existing pathspec deprecation warnings
remain.
